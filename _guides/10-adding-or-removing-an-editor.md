# 10 – Adding or removing an editor

Editors are committee members who can change the website. Each editor uses **their own free GitHub account**. The CES account adds them as a **collaborator**, so nobody needs to share the CES password to edit.

**Only the CES GitHub account can do this.** Ask whoever holds the CES login (see [09 – Committee handover](09-committee-handover.md)).

**Time:** about 5 minutes

---

## Adding an editor

### The new editor does this first

1. Create a free GitHub account at [github.com/signup](https://github.com/signup), if you don't already have one. Your own email is fine.
2. Send your **GitHub username** (shown at the top of your profile, e.g. `jsmith-jcu`) to whoever holds the CES login.

### The CES account holder does this

1. Sign in to GitHub **as the CES account** (`cairns-engineering-society`).
2. Go to the repository: https://github.com/cairns-engineering-society/cairns-engineering-society.github.io
3. Click **Settings** (the ⚙️ tab along the top of the repository. On a small screen it may be under the **⋯** menu).
4. In the left menu, click **Collaborators** (under "Access"). GitHub might ask you to confirm your password or 2FA code.
5. Click **Add people**.
6. Type the new editor's GitHub username, select them from the list, and click **Add [username] to this repository**.

### The new editor finishes it

1. Check your email (or github.com notifications) for the **invitation** and click **Accept invitation**. It expires after 7 days, so ask for a new one if you miss it.
2. Done. You can now edit. Start with [01 – Editing a page](01-editing-a-page.md).

---

## Removing an editor

Do this when someone leaves the committee or no longer needs access.

1. Sign in **as the CES account**.
2. Go to the repository → **Settings** → **Collaborators**.
3. Find the person and click **Remove** next to their name. Confirm.

Their past edits stay in the history. They just can't make new ones.

---

## Who can do what

| | Edit pages and upload files | Add/remove editors, change settings |
|---|---|---|
| Collaborator (committee editor) | ✅ | ❌ |
| CES account | ✅ | ✅ |

**Optional for the future:** GitHub can convert the CES account into an "Organization", which lets several people be full admins without sharing a login. It's not needed, and the website address stays the same if you do it. Search "GitHub convert user account to organization" if you ever want it.
