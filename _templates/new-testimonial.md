# Template: new testimonial

Use this to add a student testimonial to `testimonials.md`.
Full step-by-step guide: [05 – Adding a testimonial](../_guides/05-adding-a-testimonial.md)

## Before you start

Only publish a testimonial if the student **agreed on the form** for it to go on the website. Use their name **only** if they agreed to that; otherwise write "Anonymous".

## Steps

1. Copy everything in the box below.
2. Open `testimonials.md`, click the pencil icon, and paste it **under the "HOW TO ADD A TESTIMONIAL" note, above the other testimonials** (newest first). Leave a blank line before and after it.
3. Replace everything in `[square brackets]`. Delete the square brackets too.
4. Click **Commit changes**.

## Copy this block

```
### [First name, or "Anonymous"]: [Major, e.g. Electrical], [e.g. Graduated 2025 / 3rd year student]

> "[Their testimonial, copied from the form. Fix obvious typos but don't change the meaning.]"
```

## A finished example

```
### Sam: Electrical, Graduated 2025

> "Joining CES in first year was the best thing I did. I met the people I studied with for four years, and a CES site visit led to my placement."
```

## Tips

- Long testimonials over several paragraphs: start every paragraph with `> ` and put a line with just `>` between paragraphs.
- To remove a testimonial (e.g. the student asks), delete its whole block and commit.
