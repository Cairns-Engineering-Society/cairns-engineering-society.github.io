# Template: new tip ("Things nobody tells you")

Use this to add a tip to `things-nobody-tells-you.md`.

## Steps

1. Copy the **one line** in the box below.
2. Open `things-nobody-tells-you.md`, click the pencil icon, and paste it under the heading that fits best.
   - If there's a `*Nothing here yet.*` or `*Coming soon.*` line under that heading, replace it with your tip.
   - **Writing up one of the hidden "PLACEHOLDER TOPICS"** (e.g. 48-hour extensions)? Delete that topic from the hidden note under the heading once your tip is in. Only write what you know is correct, and link to the official JCU page.
   - If no heading fits, add a new one first: a line starting with `## `, e.g. `## Getting around Cairns`, with a blank line before and after.
3. Replace everything in `[square brackets]`. Delete the square brackets too.
4. Click **Commit changes**.

## Copy this line

```
- **[Short title]**: [One or two sentences explaining it.] [Optional link: [More info](https://the-full-link)]
```

## A finished example

This example is made up. It only shows the format.

```
- **Printing credit**: You can top up printing credit online before you get to the library. [More info](https://www.jcu.edu.au/)
```

## Tips

- Keep each tip short. If it needs a whole page, see [06 – Adding a new page](../_guides/06-adding-a-new-page.md).
- If a tip stops being true, delete it.
