# Template: new event

Use this to add an event to the table on the **Events** page (`events.md`).
Full step-by-step guide: [02 – Adding an event](../_guides/02-adding-an-event.md)

## Steps

1. Copy the **one line** in the box below (it starts and ends with `|`).
2. Open `events.md`, click the pencil icon, and paste it on a new line **directly under the last row** of the "This trimester" table. Don't leave a blank line, or the table breaks.
3. Replace each `[...]` with the real details. Delete the square brackets too.
4. Click **Commit changes**.
5. Also add the event to the **CES Google Calendar** so it appears on the home page calendar.

## Copy this line

```
| [Date, e.g. Fri 17 Oct] | [Time, e.g. 12–2pm] | [Event name] | [Location, e.g. Building A1, room 002] | [Sign-up link, or "No sign-up needed"] |
```

## A finished example

```
| Fri 17 Oct | 12–2pm | Welcome BBQ | Outside building A1 | No sign-up needed |
```

To make the last column a clickable link, write it like this: `[Sign up here](https://the-full-link)`

## Tips

- Keep events in **date order** (earliest at the top).
- Every row needs exactly **5** cells, so 6 `|` characters in total.
- If the event is cancelled, change the event name to `~~Welcome BBQ~~ CANCELLED`. The `~~` puts a line through the text.
