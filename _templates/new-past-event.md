# Template: past event

Use this to record an event CES has run in the **Past events** section of the Events page (`events.md`).
Full step-by-step guide: [02 – Adding an event](../_guides/02-adding-an-event.md)

**Upcoming events don't go on the Events page.** They go in the CES Google Calendar, which shows on the home page. Add an event here **after** it has happened.

## Steps

1. Copy the **one line** in the box below.
2. Open `events.md`, click the pencil icon ✏️, and scroll to **Past events**.
3. Find the heading for the year, e.g. `### 2026`.
   - **No heading for this year yet?** Add one **above** the other years, e.g. `### 2027`, with a blank line before and after it.
4. Paste your line **directly under the year heading**, so the newest is at the top.
5. Replace everything in `[square brackets]`. Delete the square brackets too.
6. Click **Commit changes...**, write a message like `Add T3 movie night to past events`, and click **Commit changes**.

## Copy this line

```
- **[Trimester]: [Event name]**: [One sentence about it, e.g. how many came or what happened.]
```

## A finished example

This example is made up. It only shows the format.

```
- **Trimester 3: End of trimester party**: Bowling and pizza to celebrate the end of exams. About 40 students came.
```

## Tips

- Keep it to one line per event. The point is to show new students the kinds of things CES does.
- Regular events (like a BBQ every few weeks) don't each need a line. One line per trimester is enough, e.g. `- **Trimester 3: BBQs**: Four BBQs across the trimester.`
