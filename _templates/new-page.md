# Template: new page

Use this to create a brand new page on the site.
Full step-by-step guide: [06 – Adding a new page](../_guides/06-adding-a-new-page.md)

## Steps (short version)

1. In the repository's main folder, click **Add file → Create new file**.
2. Name it in lowercase with hyphens and ending in `.md`, e.g. `study-spaces.md`.
3. Copy everything in the box below and paste it in.
4. Replace everything in `[square brackets]` and write your content.
5. Click **Commit changes**.
6. **Add a link to it from the home page** (`index.md`, under "Quick links"), otherwise nobody will find it.

## Copy this block

```
[← Back to home](index.md)

# [Page title]

[A sentence or two explaining what this page is for.]

## [First section heading]

[Your content.]

## [Second section heading]

[Your content.]

---

*Cairns Engineering Society (CES) · A student-run site, not an official JCU website · [Suggest a change](PLACEHOLDER-SUGGESTION-FORM-LINK)*
```

**Making the page inside the `subjects/` folder?** Change the first line to `[← Back to home](../index.md)`. The `../` means "go up one folder".

**Note:** if the suggestion form link has already been set up on the other pages, copy the real footer line from the bottom of any existing page instead of the one above.
