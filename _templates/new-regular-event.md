# Template: regular event

Use this to add a new type of event that CES runs regularly (like the BBQs or movie and pizza nights) to the **Our regular events** section of the Events page (`events.md`).
Full step-by-step guide: [02 – Adding an event](../_guides/02-adding-an-event.md)

## Steps

1. Copy everything in the box below.
2. Open `events.md`, click the pencil icon ✏️, and scroll to **Our regular events**.
3. Paste the block **at the end of that section**, just above `## Suggest an event`. Leave a blank line before and after it.
4. Replace everything in `[square brackets]`. Delete the square brackets too.
5. Click **Commit changes...**, write a message like `Add trivia nights to regular events`, and click **Commit changes**.

## Copy this block

```
### [Event name]

[2–3 sentences: what it is, how often it runs, where, whether it costs anything, and whether you need to sign up.]
```

## A finished example

This example is made up. It only shows the format.

```
### Trivia nights

A team trivia night with engineering and general knowledge rounds, held once a trimester. Free for CES members. Teams of up to 6, sign up on the night.
```

## Stopping a regular event

If CES no longer runs it, delete its whole block (the `###` heading and its description) and commit. If you like, add a line about it to **Past events** first.
